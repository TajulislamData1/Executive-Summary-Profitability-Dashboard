# Executive-Summary-Profitability-Dashboard
Executive Summary &amp; Profitability Dashboard – Excel Project  Developed an interactive Excel dashboard to analyze sales performance and business profitability. The dashboard presents key performance indicators (KPIs), including Total Revenue, Gross Profit, Gross Profit Margin, Total Units Sold, Total Orders, and Cost of Goods Sold (COGS).
